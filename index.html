Clover annotations test

A Yale Peabody Museum Manifest, with an AnnotationPage exported from liiive.now added through the Viewer's annotations attribute: assets/annotations/test-annotations.json. It holds two annotations, a rectangle and an ellipse. Open them from the Annotations button on the image or from Annotations in the panel.

View this example on GitHub.

Code

<script src="https://cdn.jsdelivr.net/npm/@nulib/clover/dist/web-components/index.umd.js"></script>

<clover-viewer
  iiif-content="https://manifests.collections.yale.edu/ypm/nat/6299"
  template="default"
  items="grid"
  header="false"
  annotations="assets/annotations/test-annotations.json"
>
</clover-viewer>

Steps

  1. Load Clover's script in the page's <head>.
  2. Export the annotations from liiive.now and save the file beside the page.
  3. Give the Viewer the Manifest as iiif-content and the file as annotations.

Gotchas

  • A relative path resolves against the page's address, not the site's root. On a GitHub Pages project site, ../../assets/… from the homepage leaves the repository's folder and fails to load.
  • A file on another host needs CORS headers, or the browser will not hand it to Clover.
  • Each annotation must target a Canvas in the Manifest by its exact id. liiive.now's export does.
